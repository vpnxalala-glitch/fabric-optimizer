# Auto Tower

Fabric client mod for Minecraft 1.21.11 (Java 21).

## Controls
- Hold **Space** while standing on a solid block to let the mod attempt to place one block beneath the player per tower level.
- Press **G** to toggle Auto Tower on or off.
- Rebind the toggle in **Options → Controls → Key Binds → Auto Tower**.

Requires Fabric Loader and Fabric API. Sodium can be installed alongside it.

The mod does not bypass server-side checks. Placement depends on the server accepting normal block interaction, available blocks, reach, and server rules. Some servers prohibit automated building.
